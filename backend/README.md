# Law Firm Backend

This backend serves the frontend pages and sends lawyer booking requests by email.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Create a `.env` file in this `backend` folder using `.env.example`.

3. Start the server:

```bash
npm start
```

4. Open:

```text
http://localhost:3000
```

The footer button on the index page opens `booking.html`. Submitting the form sends the details to `245123733244@mvsrec.edu.in`.
